# 微信推送

从安装包 4.4.110-11 起，LuCI 可使用 Server 酱 Turbo 推送规则更新结果。

1. 在 Server 酱 Turbo 控制台绑定微信消息通道，复制以 `SCT` 开头的 SendKey。[获取 SendKey](https://sct.ftqq.com/docs/getting-started/sendkey/)
2. 打开 LuCI 的 **服务 → iKuai Bypass → 微信推送**，填写 SendKey，开启更新结果微信推送并保存。可填写自定义标题区分路由器，例如「家里主路由」，实际标题为「家里主路由 · ikuaibypass 规则更新成功」。留空时标题从 ikuaibypass 开始。
3. 点击 **发送测试通知**，在微信查看消息。随后重启 iKuai Bypass 服务，让定时任务读取已保存的设置。

推送覆盖 LuCI 单次更新和服务中的每轮定时更新。正文包含完成时间、运行方式、各类订阅通过与拒绝数量、通过校验的条目总数和已捕获的核心异常数。条目数反映订阅校验结果，实际写入情况见 OpenWrt 的 **运行与日志**。

从 4.4.110-13 起，失败通知附上最多八类错误日志摘录，合并重复事件并显示次数。摘录包含日志标记、错误类别和可用的退出码。完整的错误上下文请在 LuCI 的 **运行与日志** 查看。

订阅下载或校验失败时，受影响的旧规则由订阅保护保留。推送使用 HTTPS 访问 Server 酱，正文只包含结果摘要。SendKey 存放在路由器私有配置中，分享完整 YAML 或备份前请移除密钥。

Server 酱受理测试通知后，可在其控制台查看通道投递情况。推送请求失败会记录到 OpenWrt 日志，更新任务保留原有结果。关闭开关、保存并重启服务即可停用更新推送。
